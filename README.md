
# Banking Analytics – Loan Portfolio & Transaction Analysis

## Project Overview

This project focuses on analysing banking loan portfolios and debit and credit transactions to understand financial performance, lending trends and loan risk.

Using Excel, SQL and Power BI, the project explores key banking metrics, identifies financial patterns and presents insights through interactive dashboards.

## Business Objectives

- Evaluate overall loan portfolio performance.
- Analyse loan defaults and delinquency rates.
- Identify state-wise and loan category-wise funding trends.
- Understand debit and credit transaction patterns.
- Compare bank-wise and branch-wise transaction performance.
- Monitor key financial metrics through interactive dashboards.

## Tools & Technologies

- Microsoft Excel
- SQL
- Power BI
- Data Cleaning & Transformation
- Data Visualisation

## Dashboard 1: Loan Portfolio Performance & Risk Analysis

### Key Performance Indicators

- **Total Funded Amount:** ₹73.27 Crore
- **Total Loans:** 65,535
- **Default Loans:** 1,020
- **Default Loan Rate:** 1.56%
- **Delinquent Loans:** 7,106
- **Delinquent Loan Rate:** 10.84%

### Key Insights

- Total loan funding reached ₹73.27 crore across 65,535 loans.
- The default loan rate was 1.56%.
- The delinquent loan rate was 10.84%, highlighting accounts requiring collection attention.
- Uttar Pradesh recorded the highest loan funding.
- Home Loans contributed the largest funding amount among the displayed product groups.
